# Yar Church Broadcast — публичные страницы

Три статические страницы, на которые ссылается экран согласия Google OAuth
приложения подготовки еженедельной трансляции: описание, политика
конфиденциальности и условия использования.

Сам инструмент живёт в отдельном приватном репозитории — здесь только эти
страницы, чтобы их можно было опубликовать через GitHub Pages.

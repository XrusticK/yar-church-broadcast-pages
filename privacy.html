Yar Church Broadcast — приложение для подготовки еженедельной трансляции богослужения. Оно работает на компьютере пользователя и не имеет серверной части. Эта страница описывает, к каким данным приложение получает доступ и что с ними происходит.

Доступ к аккаунту Google

Приложение обращается к YouTube Data API v3 от имени пользователя после того, как тот явно вошёл в свой аккаунт Google и подтвердил доступ. Запрашиваются две области доступа:

  • https://www.googleapis.com/auth/youtube — чтобы прочитать настройки предыдущей трансляции канала, создать новую запланированную трансляцию и привязать к ней постоянный ключ потока;
  • https://www.googleapis.com/auth/youtube.upload — чтобы загрузить обложку созданной трансляции.

Другие области доступа не запрашиваются. Доступ используется только к каналу того аккаунта, который сам вошёл в приложение.

Какие данные обрабатываются

  • Токен доступа Google — хранится в файле на диске компьютера пользователя и нужен, чтобы не входить заново перед каждым эфиром.
  • Сведения о трансляциях канала — название, описание, категория, настройки приватности и задержки предыдущей трансляции. Читаются, чтобы новая трансляция повторяла прежние настройки, и используются в момент её создания.
  • Идентификаторы созданных трансляций — сохраняются локально, чтобы при повторном запуске не создать дубль.

Чего приложение не делает

  • не передаёт данные третьим лицам;
  • не отправляет их на какие-либо серверы автора: серверов нет;
  • не собирает аналитику и статистику использования;
  • не читает личные данные пользователя за пределами перечисленного;
  • не удаляет видео и трансляции — ни созданные им, ни существующие.

Хранение и удаление

Все данные лежат в папке приложения на компьютере пользователя. Чтобы удалить их, достаточно удалить эту папку. Отдельно удалить сохранённую авторизацию можно, удалив файл state/google-token.json.

Отозвать доступ приложения к аккаунту Google можно в любой момент на странице myaccount.google.com/permissions. После отзыва приложение перестаёт иметь доступ к данным аккаунта.

Соответствие политике Google

Использование приложением данных, полученных через API Google, подчиняется Google API Services User Data Policy, включая требования ограниченного использования.

Пользуясь приложением, пользователь также соглашается с Условиями использования YouTube; на обработку данных YouTube распространяется Политика конфиденциальности Google.
